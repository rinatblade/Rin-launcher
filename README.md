# Rin-launcher

Лаунчер для Android TV (Xiaomi TV Stick 4K и другие приставки) в стиле iPhone: значки-суперэллипсы, плавные анимации,
стеклянный док, темы и шрифты, встроенная очистка и быстрые настройки приставки.

## Возможности

- Главный экран с часами, датой и сеткой приложений. Управление с пульта (стрелки и OK).
- Значки в форме «как на iPhone», тень, глянец, кольцо фокуса, пружинная анимация увеличения.
- Анимированный фон: плавный градиент и медленно плывущие цветные пятна. Анимации можно выключить.
- 10 тёмных и 10 светлых тем. Выбор применяется сразу.
- 40 шрифтов с поддержкой русского языка (лежат внутри приложения).
- Очистка и ускорение:
  - освободить оперативную память (завершить фоновые процессы приложений);
  - список «Мои приложения» по размеру: удалить, остановить, открыть сведения (кэш, данные, отключение);
  - список системных приложений со сведениями о каждом;
  - переключатель скорости анимаций системы (нужно одно разрешение, см. ниже);
  - очистка кэша самого лаунчера.
- Быстрые настройки приставки: сеть, Bluetooth, экран, звук, приложения, хранилище, язык, дата, разработчикам.
- Долгое нажатие OK на значке: открыть, сведения, удалить, скрыть.
- Кнопка «Меню» на пульте открывает настройки.

## Установка

1. Откройте вкладку **Releases** этого репозитория и скачайте `Rin-launcher.apk`
   (или возьмите файл из артефактов последнего запуска во вкладке **Actions**).
2. Установите на приставку любым способом (флешка, «Send Files to TV», `adb install Rin-launcher.apk`).
3. Запустите «Rin Launcher» из списка приложений.

## Сделать главным экраном

Нажмите «Домой» на пульте. Если система предложит выбрать главный экран, выберите Rin Launcher и «Всегда».
Если выбор не появился, выполните по ADB:

```
adb connect IP-приставки:5555
adb shell cmd package set-home-activity com.rin.launcher/.LauncherActivity
```

## Что Android разрешает только по ADB

Приложение без root не может само отключать системные приложения и чистить кэш чужих приложений.
Для этого есть команды с компьютера:

```
# очистить кэш всех приложений
adb shell pm trim-caches 999G

# отключить ненужное системное приложение (обратимо)
adb shell pm disable-user --user 0 имя.пакета
adb shell pm enable имя.пакета

# разрешить лаунчеру менять скорость анимаций системы
adb shell pm grant com.rin.launcher android.permission.WRITE_SECURE_SETTINGS
```

Включить отладку: Настройки → Настройки устройства → Об устройстве → 7 раз нажать «Сборка», затем
«Для разработчиков» → «Отладка по USB» или «Отладка по сети».

## Сборка

APK собирается автоматически в GitHub Actions при каждом пуше в `main` (файл `.github/workflows/build.yml`).
Локально: Android Studio (Hedgehog и новее) или `gradle assembleRelease` с JDK 17 и Android SDK 34.

## Шрифты

Вшитые шрифты распространяются по свободным лицензиям: Inter, Fira Sans, Open Sans, Roboto, Source Sans 3,
Lora, Carlito, Comic Relief, Anonymous Pro (SIL OFL), DejaVu (Bitstream Vera / Public Domain),
Liberation (SIL OFL), STIX General (SIL OFL), FreeSans и FreeMono (GNU GPL с исключением для шрифтов).
